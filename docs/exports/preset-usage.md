# Export Preset Usage Guide

## Overview

Export presets allow you to save and reuse provider-specific export settings, making it faster to distribute releases to the same platforms with consistent settings.

## Creating a Preset

1. Navigate to the Export Panel
2. Configure your export settings (artwork, metadata, format)
3. Click "Save as Preset"
4. Enter a name and select the provider
5. Optionally mark as default for that provider

## Using Presets

1. In the Export Panel, select a provider
2. If a default preset exists, it will be auto-applied
3. Use the preset dropdown to select a different preset
4. Click "Apply Preset" to populate form fields

## Preset Settings

Presets can store:
- **Artwork**: URL, dimensions, format
- **Metadata**: Genre, tags, description
- **Format**: Bitrate, audio format, sample rate
- **Provider-specific**: Any provider-specific settings

## Managing Presets

Use the Export Preset Manager to:
- View all presets
- Edit existing presets
- Delete presets
- Set default preset per provider

## Best Practices

1. Create presets for common workflows
2. Use descriptive names (e.g., "SoundCloud - Electronic")
3. Set default presets for frequently used providers
4. Update presets as requirements change
